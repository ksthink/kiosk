# 배너 갤러리 (키오스크)

행사 포스터를 한 장씩 화면에 가득 채워 보여주고, 행사 페이지에서 읽은 현재 상태(**접수중 · 접수예정 · 대기접수 · 마감**)를 하단에 표시하는 9:16 키오스크용 윈도우 앱입니다. 포스터 비율 때문에 위아래 여백이 생기면 포스터 가장자리 색으로 그라데이션을 채웁니다. 서버 없이 PC 한 대에서 동작하며, 상태는 5분마다 자동으로 다시 확인합니다.

## 내려받기

둘 다 설치 없이 실행됩니다.

- **키오스크용 (권장) · 압축 폴더**: https://github.com/ksthink/kiosk/releases/latest/download/BannerGallery-win-x64.zip
  원하는 곳(예: `C:\Kiosk`)에 압축을 풀고 `BannerGallery.exe`를 실행합니다. 매번 압축을 풀지 않아 바로 켜집니다.
- **단일 exe 파일**: https://github.com/ksthink/kiosk/releases/latest/download/BannerGallery.exe
  파일 하나라 옮기기 편하지만, 실행할 때마다 임시 폴더에 풀리느라 켜지는 데 몇 초 더 걸립니다.
- 이전 버전: [Releases](../../releases) 페이지

`main`에 푸시할 때마다 GitHub Actions가 Windows에서 새로 빌드해 Releases에 올리므로, 위 링크는 늘 가장 최근 빌드를 받습니다.

### 키오스크 PC 자동 시작

`Win + R` → `shell:startup` 입력 → 열린 폴더에 `BannerGallery.exe` 바로가기를 넣으면 Windows가 켜질 때 자동 실행됩니다. 기본 설정으로 실행되자마자 전체화면이 됩니다.

설치 없이 실행되는 포터블 exe입니다. 처음 실행하면 Windows SmartScreen 경고가 뜰 수 있는데, **추가 정보 → 실행**을 누르면 됩니다(코드 서명이 없어서 생기는 경고).

## 사용법

1. **＋ 행사 등록** → 포스터 이미지를 넣고(클릭 또는 끌어다 놓기) 행사 페이지 주소를 붙여넣으면 끝입니다.
2. 등록한 행사는 아래에 순서대로 나열됩니다. **끌어서** 순서를 바꾸고, 누르면 이미지·주소 수정이나 삭제를 할 수 있습니다.
3. 포스터는 설정한 간격(기본 8초)마다 넘어가고, 화면 하단 썸네일·화살표·좌우 스와이프로 이동할 수 있습니다. 사람이 조작하면 20초 동안 자동 넘김을 멈춥니다.
4. 키보드: **F11** 전체화면, **Esc** 해제, **←/→** 이동, **Ctrl+,** 행사 관리.

데이터(`banners.json`과 이미지)는 exe와 같은 폴더의 `banner-data`에 저장되므로 폴더째 옮기면 설정도 함께 옮겨집니다.

## 상태 판정

화면에는 사이트에 적힌 문구가 그대로 표시되고, 색만 아래 키워드로 정합니다(가장 먼저 나오는 키워드 기준).

| 상태 | 키워드 |
|---|---|
| 마감 | 접수마감, 신청마감, 모집마감, 마감(마감임박 제외), 종료, 매진 |
| 대기접수 | 대기 |
| 접수예정 | 예정, 준비중, 오픈전, 접수전 |
| 접수중 | 접수중, 신청중, 모집중, 신청가능, 접수가능, 예약가능, 진행중, 마감임박 |

상태를 읽는 위치(CSS 선택자)는 행사 관리 창 아래 **설정**에서 바꿀 수 있습니다. 키워드를 바꾸려면 `crawler.js`의 `RULES`를 수정하세요.

## 개발

```bash
npm install
npm start          # 실행
npm run dist       # Windows 포터블 exe 빌드 (dist/BannerGallery.exe)
```

`main`에 푸시하면 `build-<번호>` 릴리스가 자동으로 생깁니다. 버전 이름을 직접 붙이고 싶으면 `v1.1.0` 같은 태그를 푸시해도 같은 방식으로 릴리스됩니다. Actions 탭에서 **Run workflow**로 수동 빌드도 할 수 있습니다.
