# 배너 갤러리 (키오스크)

배너 이미지가 가로로 끊임없이 흘러가고, 각 배너 아래에 연결된 사이트의 현재 상태(**접수중 · 접수예정 · 대기접수 · 마감**)를 표시하는 윈도우 앱입니다. 서버 없이 PC 한 대에서 동작하며, 상태는 5분마다 자동으로 다시 확인합니다.

## 내려받기

- **항상 최신 exe**: https://github.com/ksthink/kiosk/releases/latest/download/BannerGallery.exe
- 이전 버전: [Releases](../../releases) 페이지

`main`에 푸시할 때마다 GitHub Actions가 Windows에서 새로 빌드해 Releases에 올리므로, 위 링크는 늘 가장 최근 빌드를 받습니다.

설치 없이 실행되는 포터블 exe입니다. 처음 실행하면 Windows SmartScreen 경고가 뜰 수 있는데, **추가 정보 → 실행**을 누르면 됩니다(코드 서명이 없어서 생기는 경고).

## 사용법

1. 실행하면 갤러리 창이 뜨고, 배너가 없으면 관리 창이 함께 열립니다.
2. 관리 창에서 이미지·링크 URL·상태 요소의 CSS 선택자를 입력하고 **테스트**로 판정을 확인한 뒤 **추가**합니다.
3. 갤러리에서 **F11**은 전체화면, **Esc**는 전체화면 해제, **Ctrl+,** 은 관리 창입니다. 배너를 클릭하면 기본 브라우저로 링크가 열립니다.

데이터(`banners.json`과 이미지)는 exe와 같은 폴더의 `banner-data`에 저장되므로 폴더째 옮기면 설정도 함께 옮겨집니다.

## 상태 판정

선택한 요소의 글자에서 가장 먼저 나오는 키워드로 판정합니다.

| 상태 | 키워드 |
|---|---|
| 마감 | 접수마감, 신청마감, 모집마감, 마감(마감임박 제외), 종료, 매진 |
| 대기접수 | 대기 |
| 접수예정 | 예정, 준비중, 오픈전, 접수전 |
| 접수중 | 접수중, 신청중, 모집중, 신청가능, 접수가능, 예약가능, 진행중, 마감임박 |

키워드를 바꾸려면 `crawler.js`의 `RULES`를 수정하세요. 상태가 자바스크립트로 그려지는 사이트는 **자바스크립트 렌더링 후 읽기**를 켜면 숨겨진 창에서 페이지를 실제로 띄워 읽습니다.

## 개발

```bash
npm install
npm start          # 실행
npm run dist       # Windows 포터블 exe 빌드 (dist/BannerGallery.exe)
```

`main`에 푸시하면 `build-<번호>` 릴리스가 자동으로 생깁니다. 버전 이름을 직접 붙이고 싶으면 `v1.1.0` 같은 태그를 푸시해도 같은 방식으로 릴리스됩니다. Actions 탭에서 **Run workflow**로 수동 빌드도 할 수 있습니다.
